Справка: откуда берутся характеристики

Программа читает только заголовки файлов — само изображение не декодируется. Ниже указано, из какого поля каждого формата берётся каждая характеристика.

Имя файла

Берётся из файловой системы и служит идентификатором записи в таблице.

Размер в пикселях (ширина × высота)

  • JPEG — маркер SOF (SOF0/SOF1/SOF2…): высота и ширина кадра.
  • GIF — Logical Screen Descriptor: поля логического экрана.
  • TIFF — теги 256 (ImageWidth) и 257 (ImageLength).
  • BMP — поля biWidth / biHeight заголовка BITMAPINFOHEADER.
  • PNG — чанк IHDR: поля Width и Height.
  • PCX — вычисляется как xmax − xmin + 1 и ymax − ymin + 1.

Разрешение (dpi)

Определяет физический размер пикселя:

  • JPEG — плотность JFIF (маркер APP0) или Exif.
  • PNG — чанк pHYs: пиксели на метр × 0,0254.
  • TIFF — теги XResolution / YResolution + ResolutionUnit.
  • BMP — biXPelsPerMeter / biYPelsPerMeter × 0,0254.
  • PCX — поля hDPI / vDPI заголовка.
  • GIF — разрешения не имеет.

Глубина цвета (бит на пиксель)

  • JPEG — точность отсчётов × число каналов.
  • GIF — разрядность индекса палитры.
  • TIFF — сумма значений тега BitsPerSample.
  • BMP — поле biBitCount.
  • PNG — бит на канал × число каналов.
  • PCX — бит на плоскость × число плоскостей.

Сжатие

  • JPEG — DCT (дискретно-косинусное преобразование).
  • GIF — LZW.
  • PNG — Deflate.
  • TIFF — тег Compression (LZW, PackBits, …).
  • BMP — biCompression (BI_RGB, BI_RLE8, …).
  • PCX — RLE.

Столбец «Доп.»

Число дополнительных характеристик файла. Клик по строке открывает подробности: таблицы квантования JPEG, палитры GIF, Exif и т.д. — каждая характеристика снабжена пояснением.
